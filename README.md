# Installation auf Linux

Schritt 1:
Terminal öffnen und Repo klonen
```bash
git clone https://github.com/Liamlol1919/SH-pygame/tree/main
```

Schritt 2:
Virtuelle Umgebung aktivieren
```bash
source venv/bin/activate
```

## Starten des Spiels
```bash
python starten.py
```
